Loading 3D Models

pixi-solid-3d provides the <Model3D> component to instantiate and render 3D scenes loaded from standard glTF and GLB files.

How Model Loading Works

  1. Load your .gltf or .glb file using PixiJS's Assets.load<Scene3DSource>().

  2. Wrap the loader with SolidJS's createResource to handle the asynchronous loading state reactively.

  3. Pass the resulting source to <Model3D source={source()} />.

Multiple <Model3D> instances can share the exact same Scene3DSource without duplicating GPU textures or geometry buffers.

Customizing Model Materials (traverse)

When a 3D model loads, @pixi/3d builds an internal hierarchy of Mesh3D nodes from the glTF file. To inspect or customize individual meshes (such as swapping materials, adjusting roughness, or setting shadow properties), use the traverse prop:

Per-model material overrides

Every <Model3D> built from the same Scene3DSource draws the same material instances. Changing a property on one writes through to every model built from that source:

When a model needs materials of its own, pass materials. @pixi/3d calls it once per source material, so meshes that shared a material still share its replacement:

materials is a setter on Model3D, so you can swap overrides from a signal, for example when a model takes damage. Assigning undefined gives the model the source's materials back.

<Model3D> never destroys the materials you pass in. Destroy the ones you created when you are done with them, or pass destroy({ material: true }) yourself.
