Creating a Pixi Application

PixiCanvas

The PixiCanvas component is the primary way to set up a PixiJS application in pixi-solid. It handles creating and managing the HTML canvas element, the Pixi Application instance, and provides context to child components.

With HTML Components

For use cases where you need HTML components outside the canvas to access pixi-solid hooks, wrap with PixiApplicationProvider:

When using PixiApplicationProvider, HTML components placed between the provider and canvas can access pixi-solid hooks and the Pixi application context.

For complete API documentation and more examples, see the PixiCanvas component reference.

The pixi-solid library only supports client side rendering. So you may need to use the lazyfunction to dynamically import only on the client or use the clientOnly function if using Solid Start.
