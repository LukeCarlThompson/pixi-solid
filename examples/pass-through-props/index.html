Pass through props

Code example

When you create custom components, it is often useful to pass props through to the underlying PixiJS components. This allows for greater flexibility by gaining access to properties such as position, scale or adding event listeners from the outside.

Instead of writing them out one by one, you can use the utility type PixiComponentProps which contains props for the PixiJS Container but you can extend it by passing in the specific component type a generic PixiComponentProps<Pixi.SpriteOptions>. It may be useful to combine with the built in Omit or Pick utility types to exclude or include specific props. Combine it with omit and the {...props} spread to pass all received props, or only a specific group, down to the underlying component. omit returns a reactive view of the remaining props.
