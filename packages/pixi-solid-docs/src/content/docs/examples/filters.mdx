To use PixiJS filters, instantiate them from the PixiJS classes, then bind the properties you want to change to signals.

Any PixiJS class you instantiate directly must be destroyed manually when the component is cleaned up. The `onCleanup` hook handles this:

Please see the [PixiJS docs](https://pixijs.download/release/docs/filters.html) for detailed information.
