Async work is a computation that returns a Promise. Return one from `createMemo` and read it inside a `<Loading>` boundary. Pair it with the PixiJS `Assets` class to load assets.

### Example: Loading a Single Image

This example loads a single background image for a scene.

```tsx
import type * as Pixi from "pixi.js";
import { Assets } from "pixi.js";
import { PixiCanvas, Sprite } from "pixi-solid";
import { createMemo, Loading } from "solid-js";

export const IndividualAssetLoadingDemo = () => {
  // Load the texture once. Reading the memo suspends, so the boundary below holds the scene
  // until the texture arrives.
  const backgroundImage = createMemo(async () => {
    const texture = await Assets.load<Pixi.Texture>("/background.png");
    return texture;
  });

  return (
    <PixiCanvas>
      <Loading>
        <Sprite texture={backgroundImage()} anchor={0.5} position={[400, 300]} scale={0.5} />
      </Loading>
    </PixiCanvas>
  );
};
```

Because the memo returns the texture, reading it both waits for the load and supplies the value, and no `<Show>` is needed. When a load produces many assets that the scene reads individually, gate it with a boolean instead. See [asset manifests](../asset-manifest).
