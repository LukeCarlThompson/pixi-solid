Find display objects by their `label` property, decoupling tests from scene graph hierarchy.

`mountScene` returns these helpers bound to the current root. The standalone form takes a root as its first argument, so it also works on any Pixi container you already hold.

## getByLabel(label)

Throws when the label is not found.

```tsx
const { getByLabel } = mountScene(() => (
  <Container label="scene">
    <Sprite label="player" x={100} />
  </Container>
));

expect(getByLabel("player").x).toBe(100);
```

The standalone form takes the root explicitly:

```tsx
const player = getByLabel(container, "player");
```

## queryByLabel(label)

Same as `getByLabel`, but returns `undefined` instead of throwing.

```tsx
const maybe = queryByLabel("missing-label"); // undefined
```

## getAllByLabel(label)

Find every display object with the given label, which is useful when a scene repeats one:

```tsx
const { getAllByLabel } = mountScene(() => (
  <Container label="scene">
    <Sprite label="enemy" />
    <Sprite label="enemy" />
  </Container>
));

expect(getAllByLabel("enemy")).toHaveLength(2);
```
