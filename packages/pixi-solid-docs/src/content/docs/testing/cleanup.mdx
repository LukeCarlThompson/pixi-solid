---
title: cleanup
description: Run all registered disposers for test teardown.
sidebar:
  order: 7
---

All disposers created by `mountScene` and `renderHook` are registered with a global registry.
Wire `cleanup()` into your test framework's lifecycle to run them automatically:

```tsx
import { afterEach } from "vitest";
import { cleanup } from "pixi-solid/testing";

afterEach(() => cleanup());
```

`cleanup()` disposes every registered root **and clears Solid's error halt**. Solid stops the whole reactive system after an uncaught error. Without the reset, one test that throws on purpose would break every later test in the file.

Once wired, you no longer need to track `dispose`:

```tsx
it("some test", () => {
  mountScene(() => <Container label="root" />);
  // cleanup runs automatically in afterEach
});
```

To unmount before the end of a test, call `dispose()` directly. It unregisters that root, so later global cleanup will not dispose it twice:

```tsx
const { dispose } = mountScene(() => <Container />);
// ... test logic ...
dispose();
```
