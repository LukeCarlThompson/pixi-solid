`mountScene()` is for testing **view components** that render a Pixi display object (Sprite, Container, Text, etc.).
It mounts JSX in a temporary Solid root, resolves it to a real Pixi node, and returns the root Container.

```tsx
type MountSceneResult<TRoot = Pixi.Container> = {
  container: TRoot;
  dispose: () => void;
};
```

The returned `container` is the root PixiJS node — no ref callback is needed to access it.

## Basic usage

```tsx
import { Container, Sprite } from "pixi-solid";
import { mountScene, getByLabel } from "pixi-solid/testing";

const { container, dispose } = mountScene(() => (
  <Container label="scene">
    <Sprite label="player" x={100} />
  </Container>
));

// Container is Pixi.Container — directly accessible
container.x;

// Query children by label
const player = getByLabel(container, "player");
expect(player.x).toBe(100);

dispose();
```

## Non-Container roots

For component types other than `Pixi.Container`, specify the type via the generic parameter:

```tsx
const { container } = mountScene<Pixi.AnimatedSprite>(() => (
  <AnimatedSprite textures={textures} playing />
));
container.playing; // typed as Pixi.AnimatedSprite
```

## Getting a nested node with a ref

`container` is the root. When you need a node below it, a `ref` is the direct way to reach it — no
label needed:

```tsx
import type * as Pixi from "pixi.js";

let player: Pixi.Sprite | undefined;

mountScene(() => (
  <Container label="scene">
    <Sprite ref={(el) => (player = el)} x={100} />
  </Container>
));

expect(player?.x).toBe(100);
```

Label queries ([scene-queries](../scene-queries)) reach nodes as well. Both are fine; use whichever
reads better in the test, and note that a `ref` also exercises the `ref` prop itself.

A `ref` only reaches an element you wrote. Nodes a component builds for you — a split text's
characters, for instance — are reached through that component's own API, or by querying the scene,
which needs the node to carry a `label`.

## When to use

- Testing view components that render a Pixi display object
- You need to inspect the rendered scene graph
- You want to query children by label with `getByLabel` / `queryByLabel`

For testing stores or hooks that don't render a scene, use [`renderHook`](../render-hook) instead.

## With context (onTick, onResize, etc.)

Wrap your component in `createTestContext().Provider` to provide a mock ticker (stopped, manually
controlled), renderer, and app context:

```tsx
import { mountScene, createTestContext } from "pixi-solid/testing";
import { Container, Sprite, onTick } from "pixi-solid";

const ctx = createTestContext();
let calls = 0;

mountScene(() => (
  <ctx.Provider>
    <Container>
      {onTick(() => {
        calls++;
      })}
      <Sprite x={100} />
    </Container>
  </ctx.Provider>
));

// Advance frames with the manual ticker
ctx.ticker.fastForwardFrames(5);
expect(calls).toBe(5);
```
