A SolidJS component that renders a PixiJS `Graphics`.

Draw with the `draw` prop. The callback runs once, then again whenever a reactive value it reads changes. The instance is cleared before every run, so the callback describes the whole content and a re-run replaces the previous drawing:

```tsx
<Graphics
  draw={(graphics) => {
    graphics.rect(50, 50, 100, 200).fill(0xff0000).circle(200, 200, 50).stroke(0x00ff00);
  }}
/>
```

Because the callback tracks what it reads, a drawing follows the values it uses:

```tsx
import { Graphics } from "pixi-solid";

const Circle = (props: { radius: number }) => (
  <Graphics
    draw={(graphics) => {
      graphics.circle(0, 0, props.radius).fill("#ffd500ff");
    }}
  />
);

// Pass a signal read and the circle redraws when the radius changes.
<Circle radius={radius()} />;
```

A value that changes every frame redraws every frame. For per-frame work, animate the instance from `onTick` instead and keep `draw` for content that follows discrete changes.

### Reading the instance

Use `ref` for anything that is not drawing, such as reading bounds:

```tsx
let graphics: Pixi.Graphics | undefined;

onSettled(() => {
  const bounds = graphics?.getLocalBounds();
});
```

See the [PixiJS docs](https://pixijs.download/release/docs/scene.Graphics.html) for the full drawing API.
