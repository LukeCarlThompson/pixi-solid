`pixi-solid-3d` extends `pixi-solid` with declarative SolidJS components for PixiJS 3D scenes powered by `@pixi/3d`.

### How 3D works in PixiJS

In PixiJS v8, 3D scenes are hosted inside a 2D viewport container called `View3D`.

- `<View3D>` is a 2D PixiJS display node that you can place inside `<PixiCanvas>` or anywhere in your 2D scene graph.
- Children placed inside `<View3D>` are automatically attached to its 3D root (`view.root`, a `Container3D`).
- Inside the 3D scene, you can place 3D containers (`<Container3D>`), meshes (`<Mesh3D>`), models (`<Model3D>`), lights (`<DirectionalLight>`, `<PointLight>`, `<AmbientLight>`), and interactive camera controls (`<OrbitCamera>`).
