`pixi-solid-3d` provides the `<Model3D>` component to instantiate and render 3D scenes loaded from standard **glTF** and **GLB** files.

### How Model Loading Works

1. Load your `.gltf` or `.glb` file using PixiJS's `Assets.load<Scene3DSource>()`.
2. Wrap the loader with SolidJS's `createResource` to handle the asynchronous loading state reactively.
3. Pass the resulting `source` to `<Model3D source={source()} />`.

Multiple `<Model3D>` instances can share the exact same `Scene3DSource` without duplicating GPU textures or geometry buffers.

### Instantiating Named Scenes

If your glTF file contains multiple scenes, specify which one to instantiate using the `scene` prop:

```tsx
<Model3D source={source()} scene="Showroom" />
```

### Shadows and Transforms

`<Model3D>` supports the full set of 3D transform props (`x`, `y`, `z`, `scale`, `rotation`, etc.) and shadow options:

```tsx
<Model3D source={source()} x={0} y={0} z={-5} scale={1.5} castShadow={true} receiveShadow={true} />
```
