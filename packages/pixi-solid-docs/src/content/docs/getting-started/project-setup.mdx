### Creating a new project

To use `pixi-solid` you need a SolidJS project. If you do not have one yet, create one with:

```bash
npm init solid@latest
```

This creates a new SolidJS project in a directory of your choice.

Next, install `pixi-solid` along with its peer dependency `pixi.js` in the project you created:

```bash
npm i pixi-solid pixi.js
```

### Existing project

If you already have a project, make sure that `pixi.js` and `solid-js` are installed. Then install `pixi-solid`:

```bash
npm i pixi-solid
```

#### Compiler setup

`pixi-solid` uses `@solidjs/web` as its JSX renderer. Point your JSX compiler at it with `"jsxImportSource": "@solidjs/web"` in `tsconfig.json`, and use `@solidjs/vite-plugin` in your Vite config.

### LLM skill

A pixi-solid skill for LLM coding assistants ships with the package. You can either:

- **Reference the path** in your `AGENTS.md` or `.cursorrules`: `node_modules/pixi-solid/dist/skills/pixi-solid/SKILL.md`
- **Install it for Agent Skills-compatible assistants**: `mkdir -p .agents/skills/pixi-solid && cp -R node_modules/pixi-solid/dist/skills/pixi-solid/. .agents/skills/pixi-solid/`

The skill covers the full public API: components, hooks, utilities, providers, and testing patterns.
